**English**: Blankspace follows your Windows display language (Chinese or English); change it in Settings → Language. See the [English README](https://github.com/yunningtang/blankspace/blob/main/README.en.md).

## 下载

- **Liubai-Setup-x.x.x.exe**：安装版。双击安装，不需要管理员权限，装在你自己的用户目录里。
- **Liubai-x.x.x-portable.zip**：便携版。解压后双击 `Liubai.exe` 就能用，不写注册表。

需要 Windows 10 或 11（64 位）。界面需要 Microsoft Edge WebView2（Windows 11 自带，大部分 Windows 10 也有；没有的话留白会告诉你去哪下载）。

> 这个程序没有数字签名，第一次打开时 Windows 可能提示“Windows 已保护你的电脑”。点“更多信息”→“仍要运行”。

## 用之前

第一次在自己的电脑上用，请先看一遍 [安全与流程](https://github.com/yunningtang/blankspace/blob/main/docs/安全与流程.md) 最后的清单，在不重要的文件上试一试。
