# 开发说明

## 结构

```
main.py            入口：用 pywebview 打开 webui/；没有 WebView2 时说明原因并给下载地址
devserver.py       开发用：在浏览器里打开界面，后端是真的 Api
webui/             界面：index.html、app.css、ink.js（纸和墨的几何与纹理）、app.js（界面逻辑）
core/
  api.py           界面和后端之间唯一的接口，不依赖 pywebview，可以直接测试
  safety.py        什么不能动：系统、程序数据、个人文件夹本身、OneDrive、链接；可清理缓存的名单
  recycle.py       唯一真正把文件移到回收站的地方（先确认能进回收站）
  cleaner.py       删除流程：preflight（只读预检）→ execute（逐项再查一次后移到回收站）
  mover.py         移动流程：plan_moves → execute_moves → undo，每一批都能撤销
  tree.py          选了地方以后的文件夹树扫描（只读，后台低优先级，可暂停/取消，结果存成快照）
  places.py        有哪些盘、常用文件夹在哪（不读文件）
  procs.py         正在运行的程序，按内存合并；谁在用哪个缓存
  naming.py        按拍摄时间重命名、版本混乱的建议（只读，执行走 mover）
  winshell.py      在资源管理器中打开 / 选中文件、选择文件夹对话框
  scanner.py       大文件扫描（只读）
  space.py         空间分类统计（只读）
  inspect.py       “看看里面”的建议（只读）
  dupes.py         重复文件（只读）
  tidy.py          整理下载和桌面的建议（只读）
  cleanables.py    可放心清理的项目
  oplog.py         每一项操作的记录（JSON Lines）
  prefs.py         用户说过“留着”的文件、是否允许整理和清理（默认不允许）
tests/             pytest
```

## 规则

- 只有 `recycle.py` 能把文件移到回收站，只有 `mover.py` 能移动文件。其他地方禁止调用 `os.remove`、`shutil.rmtree`、`send2trash` 等，测试会检查。`mover.py` 里删除只允许出现在三个函数里（删掉已核对的原件、清掉自己没复制完的临时副本、撤销后删掉自己建的空文件夹）。
- 所有动文件的操作都分两步：只读的预检 → 用户确认 → 执行时逐项再查一次。
- 扫描、建议、重复文件、整理建议都是只读的。
- 界面只调用 `Api`，从不直接动文件。耗时的事都在后台线程，界面只在扫描或执行时轮询 `state()`。
- 打开时不扫描。只有用户选了盘或文件夹才扫，看过的地方用快照，不重复读硬盘。
- “允许整理和清理”关着时，`plan`、`execute`、`undo`、`end_processes` 都会拒绝（后端检查，不只是界面）。
- 画面只在内容变化或窗口大小变化时重画到缓存图上；鼠标移动只在上面叠一层高亮。
- 判断“很久没用”只看修改时间，不看访问时间。
- 新增受保护的位置或可清理的缓存，只改 `safety.py`。缓存位置参考了 [BleachBit](https://github.com/bleachbit/bleachbit/tree/master/cleaners) 和 [Winapp2](https://github.com/MoscaDotTo/Winapp2)（只参考了路径，没有用它们的代码）。只收“删了会自动重新生成”的缓存；登录状态、网站离线数据、聊天记录、日志里的使用痕迹都不收——留白清的是空间，不是隐私。
- 图标由 `packaging/make_icon.py` 生成。
- 介绍页在 `site/`（中英文，首屏是用 `webui/ink.js` 画的水墨演示）。`python site/build.py _site` 拼成可以发布的文件夹，推到 main 后由 `.github/workflows/pages.yml` 发布到 GitHub Pages。
- 英文：核心逻辑只说中文，`core/i18n.py` 在 `Api` 的公开方法返回时统一翻译（方法之间互相调用时不翻）。带变量的句子用模板，`{}` 是变量。界面的字在 `webui/app.js` 里写成 `L("中文", "English")`。`tests/test_i18n.py` 检查每句中文都有英文，并在英文下走一遍完整流程。

详细的规则和原因见 [安全与流程](安全与流程.md)。

## 测试

```bash
pip install pytest
```

```bash
python -m pytest tests
```

全部测试都在临时文件夹里进行，回收站用假的代替。`test_safety_flow.py` 一条安全规则一个测试；`test_mover.py` 是移动和撤销；`test_tree.py`、`test_procs.py`、`test_naming.py` 是新模块；`test_api.py` 是完整流程。

## 在浏览器里调界面

```bash
python devserver.py
```

然后打开它打印出来的地址（带 `?token=…`，每次启动都不一样；没有口令的请求会被拒绝，防止本机别的网页调用）。后端是真的，会真的移动文件——请把 `HOME` / `USERPROFILE` / `LOCALAPPDATA` 指向测试用的文件夹再启动。

## 视觉

- 只有纸和墨，没有彩色。颜色、字号都在 `webui/app.css` 开头；字号只用五档。
- 墨色按大小分五级；可用空间是纸，所有文字写在纸上。
- 文字说人话：说“为什么”，不说路径和扩展名；后果在确认时说。
